¿Qué es una dirección IP?

Una dirección IP es como la dirección postal de cada dispositivo en una red. Así como cada casa tiene una dirección única, cada computadora, teléfono o router tiene una dirección IP que permite identificarla y enviarle datos.

Tu PC en casa
192.168.1.10
Google.com
142.250.80.46
Tu router
192.168.1.1

Estructura de IPv4 — 32 bits interactivos

Una dirección IPv4 tiene 32 bits divididos en 4 grupos de 8 bits (octetos). Cada octeto se escribe en decimal. Haz clic en los bits para cambiarlos.

Clases de direcciones IPv4

El primer octeto (o primeros bits) determina la clase de la dirección, que define cuántas redes y cuántos hosts por red son posibles.

IPv6 — El futuro del direccionamiento

IPv4 permite ~4.300 millones de direcciones. Con el crecimiento de internet, se agotaron. IPv6 usa 128 bits y permite 340 sextillones de direcciones (3,4 × 10³⁸).
