Terminal simulada de captura de red

Escribe comandos como tcpdump, curl, dig, nslookup o ping igual que en una práctica real. Cada captura que cierres queda lista para descargar en formato .pcap y .txt, compatibles con el simulador de Wireshark del curso. Todo corre en tu navegador — no se sube nada a ningún servidor.

01 Cómo funciona

Primero abres una captura con tcpdump -w archivo.pcap <filtro>. Mientras esa captura está activa, todo el tráfico que generes con curl, dig, nslookup o ping se agrega al archivo si coincide con el filtro — exactamente igual que con un tcpdump real. Al abrir un tcpdump nuevo (o escribir stop/exit) la captura anterior se cierra y queda disponible para descargar más abajo.

Ejemplo clásico — HTTP en claro vs. HTTPS cifrado:

# HTTP visible
sudo tcpdump -i eth0 -nn -s 0 -w http_plain.pcap tcp port 80
curl http://example.com

# HTTPS protegido
sudo tcpdump -i eth0 -nn -s 0 -w https_tls.pcap tcp port 443
curl https://example.com
tcpdump -i eth0 -w archivo.pcap <filtro>
