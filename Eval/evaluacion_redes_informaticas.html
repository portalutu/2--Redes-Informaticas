Sección 2 — Capa de Transporte (Capa 4) y Capa de Sesión (Capa 5)

Cada capa del modelo OSI trabaja con su propia unidad de datos. ¿Cuál corresponde a la capa 4?
ABit
BTrama
CPaquete
DSegmento (o datagrama en UDP)
07 ¿Qué diferencia principal existe entre TCP y UDP? Capa 4
Ambos protocolos operan en capa 4, pero tienen características muy distintas.
ATCP usa puertos y UDP no utiliza puertos
BTCP garantiza entrega confiable, orden y control de flujo; UDP no garantiza entrega ni orden
CUDP es más lento que TCP en todos los casos
DTCP se usa para video en tiempo real y UDP para descarga de archivos
08 ¿Cuántos pasos tiene el three-way handshake de TCP y cuáles son? Capa 4
Antes de transmitir datos, TCP establece una conexión mediante un proceso específico.
A2 pasos: SYN → ACK
B3 pasos: SYN → SYN-ACK → ACK
C4 pasos: SYN → SYN-ACK → ACK → DATA
D1 paso: el cliente envía un paquete DATA directamente
09 ¿Cuál es la función principal de la capa de Sesión (capa 5)? Capa 5
La capa 5 del modelo OSI tiene una responsabilidad diferente a la de las capas inferiores.
ATransmitir bits por el medio físico (cables, fibra, radio)
BEnrutar paquetes entre redes diferentes usando tablas de rutas
CGestionar el ciclo de vida de conversaciones entre aplicaciones: apertura, mantenimiento, sincronización y cierre
DAsignar direcciones IP automáticamente a los dispositivos de la red
10 ¿Qué función cumple la capa de Presentación (capa 6)? Capa 6
La capa 6 se ocupa del formato de los datos para que los sistemas puedan interpretarlos correctamente.
AControlar el acceso al medio físico y gestionar colisiones
BEnrutar paquetes entre redes y mantener tablas de enrutamiento
CTraducir formatos, codificar, comprimir y cifrar datos para que sistemas distintos los entiendan
DSegmentar datos y controlar el flujo entre extremos

15 ¿Cuántos bits tiene una dirección IPv6 y por qué fue necesario crearlo? Protocolo IP
IPv6 fue diseñado para reemplazar a IPv4 ante el agotamiento de direcciones disponibles.
A32 bits — el mismo que IPv4 pero con mejor enrutamiento
B64 bits — el doble de IPv4 para duplicar el espacio de direcciones
C128 bits — representados en hexadecimal, con espacio de direcciones prácticamente ilimitado
D256 bits — para garantizar seguridad criptográfica en el direccionamiento
Sección 4 — Protocolos, Puertos y Seguridad de Red
16 ¿Qué puerto utiliza HTTPS y qué protocolo de seguridad agrega sobre HTTP? Puertos

APuerto 80 — protegido con IPSec
BPuerto 22 — protegido con SSH
CPuerto 53 — protegido con DNSSEC
DPuerto 443 — protegido con TLS (Transport Layer Security)
17 ¿Qué significa la secuencia DORA en el protocolo DHCP? Puertos
DHCP asigna configuración de red automáticamente mediante un intercambio de mensajes con un orden específico.
AData, Order, Request, Acknowledge
BDiscover, Offer, Request, Acknowledge
CDetect, Obtain, Relay, Assign
DDispatch, Offer, Register, ACK
18 ¿Qué ataque de capa 2 satura la tabla MAC de un switch para que reenvíe tráfico a todos los puertos? Seguridad
Un atacante puede explotar un comportamiento específico de los switches cuando su tabla de direcciones se llena.
AARP Spoofing — asocia una MAC falsa a una IP legítima
BVLAN Hopping — salta entre VLANs sin autorización
CMAC Flooding — inunda la tabla MAC del switch con direcciones falsas hasta que se comporta como hub
DDHCP Snooping — bloquea servidores DHCP no autorizados
19 ¿Cuál de los siguientes NO es un protocolo de enrutamiento dinámico? Enrutamiento
Los protocolos de enrutamiento dinámico permiten que los routers aprendan rutas automáticamente. Uno de los siguientes no cumple esa función.
AOSPF (Open Shortest Path First)
BBGP (Border Gateway Protocol)
CRIP (Routing Information Protocol)
DFTP (File Transfer Protocol)
